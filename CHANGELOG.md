# Изменения

Все заметные изменения проекта **Dyni**.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [3.6.0] — 2026-06-21

Друзья.

### Добавлено
- **Друзья и статус «играет в…».** Добавляй игроков по **нику или UUID**, принимай и отклоняй заявки, отменяй свои; видь, кто **в сети** и в какую сборку играет. Заявки, принятия и статусы прилетают **мгновенно** (Appwrite Realtime, с поллингом-фолбэком), на аккаунте в сайдбаре — счётчик входящих заявок. Своя UUID-метка с копированием — поделись, чтобы тебя добавили.
- Только для **лицензионных (Microsoft)** аккаунтов — там настоящий неподделываемый MC-UUID; он же идентичность, поэтому друзья не теряются при переустановке лаунчера.

## [3.5.2] — 2026-06-21

### Добавлено
- **Студия фона.** Настройки → Внешний вид → «Фон лаунчера» → «Открыть студию»: полноэкранная панель с живым превью (фон + макет лаунчера) и кнопкой «Скрыть интерфейс». **17 стилей** фона — Аврора, Поток, Плазма, Меш-градиент, Шёлк, Волны, Градиент, Голограмма, Каустика, Жидкость, Дым, Космос, Боке, Калейдоскоп, Дождь, Огонь, Классика. Цвет (под тему / свой, два оттенка), скорость, яркость, масштаб.
- **Эффекты-оверлеи** поверх любого стиля: пиксели (чанки), размытие, виньетка, зерно и сканлайны (CRT).

### Изменено
- Старый тумблер «Живой фон» из 3.5.1 заменён Студией фона; настройки сохраняются. Плоские темы (Dark / AMOLED) и режим «без анимаций» по-прежнему отключают фон.

## [3.5.1] — 2026-06-21

### Добавлено
- **Производительная Java под каждую версию.** Настройки → Запуск и Java: ставится оптимальный рантайм (Adoptium Temurin) — Java 8 для 1.8–1.16, Java 21 для 1.17–1.21, Java 25 для 26.x. После установки лаунчер сам подбирает лучшую Java под версию сборки при запуске; кнопки «Установить» / «Удалить» с прогрессом. Даёт плавность (меньше микролагов), а не больше среднего FPS.
- **Живой фон.** Настройки → Внешний вид: анимированный шейдерный фон, перетекающий под цвет темы. Выключено — спокойный статичный фон; в плоских темах (Dark / AMOLED) и режиме «без анимаций» отключён.

### Улучшено
- Логотип доведён до прозрачного скруглённого значка (без белых/чёрных углов) — в лаунчере, иконке окна/exe и favicon. Обновлён README.

## [3.5.0] — 2026-06-20

Стабильный релиз ветки **3.5** — большой проход по настройкам, скинам/аккаунтам, бэкапам и производительности, плюс новый логотип.

### Добавлено
- **Полная переработка настроек.** Боковое меню разделов (Общее · Внешний вид · Запуск и Java · Хранилище · Логи · Обновления · О программе) + поиск по настройкам по всем разделам. Все параметры перевязаны без потерь; добавлены глобальный путь к Java и раздел «О программе».
- **Новый логотип** во всём лаунчере: титлбар, пустые экраны, «О программе», иконка окна/exe и favicon.
- **Плащи и скины для ely.by / LittleSkin прямо в лаунчере.** Открываешь «Скины» у Yggdrasil-аккаунта — видишь свой скин и плащ в 3D (просмотр; меняются на сайте провайдера, кнопка «Управлять на сайте» рядом).
- **Перетаскивание скина на 3D-превью** (Microsoft и offline) — брось PNG прямо на модельку, он сразу показывается, потом загружается.
- **Проверка PNG до отправки** — понятное сообщение про размер 64×64 / 64×32 и вес вместо непонятной ошибки «400».
- **Поиск, фильтр по провайдеру и массовое удаление аккаунтов** (когда их несколько): чекбоксы, «выбрать все», удаление выбранных с подтверждением.
- **Кнопка «Бэкап перед модпаком»** в плашке обновления сборки — снимок `saves/` + `config/` одним кликом перед рискованным апгрейдом.
- **Перед восстановлением бэкапа** показывается, какие папки перезапишутся и сколько данных там сейчас.
- **Горячие клавиши:** Ctrl+T — смена темы, Ctrl+1/Ctrl+2 — Главная/Игра, Ctrl+, — Настройки, Ctrl+F — поиск; точка-пульс обновления в шапке; экспорт логов в zip.
- **Умные JVM-пресеты:** предупреждения о конфликтах флагов, рекомендация пресета под ОЗУ/Java, подсказки на каждый флаг, отмена изменений, запоминание `-Xmx` под пресет, разбор причины «не удалось создать JVM».

### Улучшено
- **Бэкапы миров:** политика хранения (оставлять N свежих + «Очистить старые»), заметки и теги с поиском, авто-дедупликация одинаковых снапшотов.
- Скины и плащи кешируются на диск — не перекачиваются при каждом запуске.
- Список скриншотов и заметки бэкапов не тормозят на больших объёмах.
- Единые компоненты тумблера и сегмент-контрола по всему экрану настроек; адаптив на узких окнах (container query); контраст вторичного текста и доступность (aria-метки, фокус, роли); вычитан копирайт.

### Производительность
- **Параллельная распаковка нативных библиотек** — запуск быстрее.
- Прогресс установки модпака шлётся пачками (тысячи событий → десятки) — плавнее, меньше нагрузка.
- Кеш скинов перенесён в IndexedDB — не блокирует первый показ интерфейса.
- Бандл разбит на отдельные чанки — быстрее старт.

### Исправлено
- Восстановление снапшота «перед модпаком» больше не может затереть миры, которых не было на момент снимка (раньше чистились обе папки `saves/` + `config/` вне зависимости от содержимого архива).
- Поиск по настройкам находит синонимы (xmx, javaw и т. п.); заголовок раздела больше не показывается без содержимого.
- Путь к Java можно вводить с пробелами; индикатор занятости показывается на нужной кнопке сброса хранилища.

## [3.1.0] — 2026-06-19

Большой проход по надёжности, безопасности и производительности по итогам полного аудита кода.

### Исправлено
- **Защита от двойного запуска одной сборки.** Серверная блокировка не даёт запустить два процесса игры в одну папку (раньше можно было обойти и повредить мир).
- **Целостность загрузок.** Моды без хеша, библиотеки загрузчиков и установщики теперь проверяются по размеру/Content-Length — обрыв связи больше не сохраняется как «успех» (это вызывало «в лаунчере мод есть, в игре нет»).
- Лог игры больше не обрывается на «битой» строке (не-UTF8); вход Microsoft не виснет на застрявшем поллинге; ложное «нет лицензии» при сетевом сбое убрано; повторный запуск exe фокусирует уже открытое окно.
- Восстановление бэкапа мира не затронет соседний мир; обновление проверяет размер скачанного установщика; «Стоп» бьёт только по процессу игры.

### Производительность
- **Параллельная загрузка** библиотек загрузчиков и файлов модпаков (.mrpack) — заметно быстрее установка.
- Убрана дорогая анимация фильтра на обложках версий; каталог Modrinth/CurseForge не перерисовывается целиком при прокрутке; 3D-просмотр скина грузится по требованию (быстрее старт).

### Безопасность
- Локальный сервер скинов отвечает только на свой адрес (защита от обращений из браузера); согласована политика доверенных хостов загрузок.

## [3.0.0] — 2026-06-19

Первый **стабильный** релиз ветки 3.0 — большое обновление: единый каталог Modrinth + CurseForge, командная палитра, скины в офлайне прямо в игре, аккаунты Yggdrasil, Discord Rich Presence, главная страница, полный редизайн интерфейса и адаптив. Финальным штрихом — версионно-безопасные JVM-флаги и переработанная система готовых пресетов запуска.

### Добавлено
- **Готовые пресеты запуска — 11 штук, с полным описанием.** Сборщики мусора под сценарий (тяжёлый модпак · сбалансированный · лёгкий/ванила · минимум подлагиваний на G1 · ZGC · слабый ПК/мало ОЗУ · максимальная пропускная способность) и тумблеры совместимости (старый Forge ≤1.12 · UTF-8 в логах · сначала IPv4 · принудительно с экраном). У каждого — когда брать, рекомендованное ОЗУ с кнопкой «поставить», требование к Java, плюсы/минусы и точные флаги.
- Единый каталог **Modrinth + CurseForge** (моды, сборки, ресурспаки, шейдеры, миры), командная палитра **Ctrl+K**, популярные сборки на главной, страница версии с markdown-описанием и выбором версии, аватарки сборок.
- **Офлайн-скины прямо в игре** (локальный skin-сервер + authlib-injector), аккаунты **ely.by / LittleSkin**, **Discord Rich Presence**.

### Исправлено
- **Пресет низких пауз (ZGC) больше не роняет игру.** Лаунчер определяет версию Java рантайма и сам убирает несовместимые флаги (`-XX:+ZGenerational` — только Java 21+, `UseZGC`/`ZUncommit` — 15+, Shenandoah — всегда), поэтому ни один пресет или ручной флаг не приводит к «Could not create the Java Virtual Machine». На Java 17 ZGC работает в обычном режиме, на Java 21 — генерационный.
- Из набора Aikar убран устаревший флаг, спамивший предупреждением на Java 21; пресет максимальной пропускной способности больше не содержит цель паузы, противоречившую его смыслу.

### Примечание
- Это **стабильный** релиз: ин-лаунчер обновление теперь предлагает 3.0.0 всем — и бета-тестерам, и пользователям 2.5.x.

## [3.0.0-beta.2] — 2026-06-18 (бета)

Надёжность установки сборок и качество жизни. Главное — починен баг, из-за которого скачанная CurseForge-сборка запускалась без части модов.

> Это **бета** — ставится вручную; стабильным версиям авто-обновление её не предлагает. Нашли баг — пишите в issues.

### Исправлено
- **Сборки больше не ставятся «наполовину».** Раньше при скачивании большой CurseForge-сборки часть модов (включая обязательные библиотеки) могла молча не докачаться — лаунчер писал «готово», а игра запускалась без модов или вылетала. Теперь каждый файл проверяется по SHA1 и размеру, есть повторные попытки с backoff, запасной источник для модов с закрытой ссылкой и финальный досбор; если что-то всё же не дошло — лаунчер честно об этом скажет.
- **Двойной запуск.** Пока версия уже запущена, повторный запуск блокируется (раньше это могло осиротить процесс или запустить две копии в одной папке — порча мира).
- **429 при входе Microsoft.** Шаги входа теперь переживают «too many requests» и сетевые сбои (повтор с backoff) — не нужно перезаходить вручную.

### Добавлено
- **Прогресс-бар при скачивании.** В выборе версии и при установке сборки виден живой прогресс (проценты для файла, «N/М файлов» для сборки).
- **Закрепить сборку на будущее** — закладки прямо из каталога (Modrinth и CurseForge), отдельная секция «Закреплённое».
- **Уведомление об обновлении переехало к аккаунту** — аккуратный плавающий тост над плашкой профиля (вместо широкой плашки сверху).

### Изменено

- **Каталог модов (Modrinth)** — встроенный поиск по Modrinth прямо в профиле: установка совместимой версии в `mods/`, включение/выключение и удаление модов. Файлы качаются только с доверенных хостов и проверяются по SHA512/SHA1.
- **Контент профиля** — раздел «Контент»: миры (имя, режим, последний вход, размер — читается из `level.dat`), список серверов с фавиконами (`servers.dat`), ресурспаки и шейдерпаки. Кнопка «Открыть папку» для каждого раздела.
- **Быстрый вход на сервер** — кнопка «Войти» у сервера запускает игру сразу с подключением (`--quickPlayMultiplayer` для 1.20+, `--server/--port` для старых версий).
- **Скины и плащи** — для Microsoft-аккаунта: 3D-превью персонажа (вращение мышью), смена модели рук Classic/Slim, загрузка своего PNG-скина, выбор плаща из доступных аккаунту или его скрытие.

### Заметка
- Моды требуют выбранного загрузчика (Fabric/Quilt) — на vanilla каталог недоступен.
- Управление скинами и плащами работает только с лицензионным Microsoft-аккаунтом.

## [1.0.0] — 2026-06-13

Первый релиз. 🎉

### Добавлено

- **Менеджер версий** — список релизов и снапшотов прямо от Mojang, с фильтром
  «релизы / снапшоты». Кэш манифеста с TTL 24 ч и ETag — быстрый холодный старт.
- **Движок загрузки** — параллельное скачивание `client.jar`, библиотек и ассетов
  с проверкой SHA1, атомарной записью (temp → rename) и ретраями при сбоях сети.
  Общий контент-адресный кэш — файлы не дублируются между инстансами.
- **Управление Java** — автоматическая установка нужного рантайма Mojang под версию
  игры, плюс детект уже установленной в системе Java.
- **Аккаунты**
  - *Offline* — по нику (корректный UUID как у ванильного сервера).
  - *Microsoft* — вход по коду устройства (Xbox → XSTS → Minecraft) с проверкой
    лицензии; refresh-токен хранится в Windows Credential Manager, не на диске.
  - Несколько аккаунтов, переключение активного.
- **Инстансы** — несколько профилей с изолированными игровыми папками и своей
  версией; создание, выбор, удаление.
- **Запуск** — `javaw` со скрытой консолью, потоковый вывод логов игры прямо в
  лаунчер, определение падений по коду выхода.
- **Настройки** — ползунок оперативной памяти (Xmx = Xms), число параллельных
  загрузок, дополнительные JVM-аргументы.
- **Интерфейс** — тёмная тема: сайдбар (аккаунты + инстансы), экран запуска с
  многофазным прогрессом и живой консолью.
- **Дистрибуция** — portable `.exe` (без установки) и установщик NSIS с
  подписанным авто-обновлением.

### Известные ограничения

- Microsoft-вход требует собственный Azure client_id (по умолчанию — заглушка);
  задаётся через переменную окружения `DYNI_AZURE_CLIENT_ID`.
- Очень старые версии (≤ 1.7) используют «виртуальные» ассеты по именам — пока не
  реализовано; сам запуск работает, но возможны пропавшие звуки/текстуры.
- Повторный запуск перепроверяет хеши всех файлов (чуть медленнее, зато надёжно).
