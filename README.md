# 🎮 Dyni

**Минималистичный лаунчер Minecraft: Java Edition для Windows.**

Управление версиями (ваниль + снапшоты) и запуск — проверенные параллельные
загрузки, offline- и Microsoft-аккаунты, мульти-инстансы.

Собран на **Tauri 2 + Rust + React/TypeScript**. Автор — **WaitDino**.

</div>

---

## Возможности

- 📦 **Версии** — список релизов и снапшотов от Mojang (кэш с TTL/ETag, быстрый старт)
- ⬇️ **Загрузка** — параллельно, проверка SHA1, атомарно, с ретраями; общий кэш между инстансами
- ☕ **Java** — авто-установка нужного рантайма Mojang + детект системной
- 👤 **Аккаунты** — offline (по нику) и Microsoft (вход по коду, проверка лицензии)
- 🗂 **Инстансы** — несколько профилей с изолированными игровыми папками
- ▶️ **Запуск** — скрытая консоль, живой лог игры прямо в лаунчере
- ⚙️ **Настройки** — оперативка, параллельные загрузки, JVM-аргументы
- 🌙 **Интерфейс** — тёмная тема, без лишнего

## Загрузка

Бери в разделе [**Releases**](https://github.com/ExtraTools/DyniLauncher/releases):

| Файл | Что это |
|------|---------|
| `Dyni.exe` | **Portable** — просто запусти (нужен WebView2, есть на Windows 10/11) |
| `Dyni_1.2.0_x64-setup.exe` | **Установщик** (NSIS, авто-обновление, ярлык в меню) |

## Быстрый старт

1. Запусти `Dyni.exe` (или поставь установщиком).
2. Слева добавь **offline-аккаунт** (по нику) или войди через **Microsoft**.
3. Создай **инстанс** — выбери версию (например, `1.20.4` или `1.21`).
4. Жми **«Играть»** — пойдёт установка (метаданные → Java → файлы → запуск).

## Настройка

- **Microsoft-вход** требует свой Azure Entra app (device-code + доступ к Minecraft API).
  Задай `DYNI_AZURE_CLIENT_ID`; значение по умолчанию — заглушка для разработки.
- **Данные** лежат в `%APPDATA%\com.waitdino.dyni\` (приватная папка, не общий `.minecraft`).
- **Авто-обновление**: адрес и подпись настраиваются в `tauri.conf.json`
  (`plugins.updater`), приватный ключ — в `src-tauri\.keys\` (не в репозитории).

## Сборка из исходников

```powershell
pnpm install
pnpm tauri dev          # запуск в режиме разработки
pnpm tauri build        # сборка установщика
```

Нужны Rust (stable-msvc), MSVC build tools, Node + pnpm.
